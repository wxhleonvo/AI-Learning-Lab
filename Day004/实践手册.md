# Day004 实践手册：ChatOptions 与 Model Parameters

> 所属阶段：Phase 1 —— LLM 基础能力  
> 路线位置：Day001 → 第一次 LLM 调用；Day002 → Prompt + Message Role；Day003 → 多轮对话 / History；**Day004 → ChatOptions / Model Parameters**；Day005 → Streaming  
> 今日目标：理解“模型看到了什么”和“模型如何生成”是两个不同问题，掌握 `ChatOptions` 的核心参数，并通过对比实验观察参数变化。

---

## 0. 今天必须掌握的结论

Day003 解决：

```text
模型看到了什么？
        ↓
Chat History
```

Day004 解决：

```text
模型应该怎么生成？
        ↓
ChatOptions
```

因此一次 LLM 请求可以逐渐抽象成：

```text
Prompt
   +
History
   +
ChatOptions
   +
Model
   +
Provider
   ↓
IChatClient
   ↓
LLM
   ↓
ChatResponse
```

当前 Microsoft `ChatOptions` 提供了多个聊天请求选项，包括 `MaxOutputTokens`、`ModelId`、`Temperature`、`TopP`、`TopK`、`FrequencyPenalty`、`PresencePenalty`、`StopSequences`、`ResponseFormat`、`Reasoning`、`Tools`、`ConversationId` 等。citeturn0search0turn0search3

**今天不要一次学完全部属性。**

重点掌握：

```text
1. MaxOutputTokens
2. ModelId
3. Temperature
4. TopP
5. StopSequences
```

其中 `Temperature` 控制生成随机性，较低值通常意味着更低随机性；`MaxOutputTokens` 控制生成响应允许达到的最大 token 数量。citeturn0search4turn0search1

## 2.2 Temperature 官方 API

https://learn.microsoft.com/en-us/dotnet/api/microsoft.extensions.ai.chatoptions.temperature

只看 `Temperature`。

理解：

```text
较低
 ↓
通常更不随机

较高
 ↓
通常更随机
```

不要死记：

```text
0 = 一定正确
1 = 一定错误
```

这是错误理解。

Temperature 是生成过程中的随机性控制参数，不是准确率开关。citeturn0search4

# 6. 实验一：默认 ChatOptions

先写：

```csharp
using Microsoft.Extensions.AI;
using Microsoft.Extensions.Configuration;
using OpenAI;

IConfigurationRoot config = new ConfigurationBuilder()
    .AddUserSecrets<Program>()
    .Build();

string? model = config["ModelName"];
string? key = config["OpenAIKey"];

IChatClient client =
    new OpenAIClient(key)
        .GetChatClient(model)
        .AsIChatClient();

string prompt = """
请解释什么是 RAG。
要求：
1. 面向刚开始学习 AI 的 C# 开发者
2. 使用中文
3. 不超过 200 字
""";

ChatResponse response =
    await client.GetResponseAsync(
        prompt,
        new ChatOptions());

Console.WriteLine(response.Text);
```

运行：

```powershell
dotnet run
```

# 14. 非常重要：统一抽象 ≠ 所有参数完全一致

这是今天必须建立的工程认知。

虽然：

```text
IChatClient
ChatOptions
```

提供统一抽象：

```text
业务代码
   ↓
IChatClient
   ↓
Provider
```

但是：

```text
统一抽象
≠
所有 Provider 完全支持所有参数
```

例如：

```text
Provider A
支持：
Temperature
TopP
MaxOutputTokens

Provider B
可能：
Temperature 有自己的限制
TopP 行为不同
某参数不支持
```

因此以后做：

```text
OpenAI
DeepSeek
阿里云 Qwen
Azure OpenAI
本地模型
```

不能把 Provider 判断散落在业务代码里。

最终应该演进成：

```text
Application
      ↓
IChatClient
      ↓
Provider Adapter
      ↓
具体 Provider
```

这就是你之前提出的：

> “灵活配置，可切换不同供应商。”

**Day004 不实现完整 Provider Factory。**

# 16. 读取配置

加入：

```csharp
IConfigurationRoot config =
    new ConfigurationBuilder()
        .AddJsonFile("appsettings.json")
        .AddUserSecrets<Program>()
        .Build();

int maxOutputTokens =
    config.GetValue<int>("AI:MaxOutputTokens");

float temperature =
    config.GetValue<float>("AI:Temperature");

float topP =
    config.GetValue<float>("AI:TopP");
```

然后：

```csharp
ChatOptions options = new()
{
    MaxOutputTokens = maxOutputTokens,
    Temperature = temperature,
    TopP = topP
};
```

请求：

```csharp
ChatResponse response =
    await client.GetResponseAsync(
        prompt,
        options);
```

+
