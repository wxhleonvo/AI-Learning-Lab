## 8. 第一次调用

核心代码：

```csharp
using Microsoft.Extensions.AI;
using OpenAI;

IConfigurationRoot config = new ConfigurationBuilder()
    .AddUserSecrets<Program>()
    .Build();

string? model = config["ModelName"];
string? key = config["OpenAIKey"];

IChatClient client =
    new OpenAIClient(key)
        .GetChatClient(model)
        .AsIChatClient();

string prompt = "请用一句中文解释什么是人工智能。";

ChatResponse response =
    await client.GetResponseAsync(prompt);

Console.WriteLine(response.Text);
```

如果当前 SDK API 与示例有差异，**以官方 Quickstart 当前代码为准**。

运行：

```bash
dotnet run
```

把真实输出写进 `notes.md`。

## 10. 必须理解

### IChatClient

应用程序与聊天模型交互的抽象接口，不是模型本身。

### GetResponseAsync

发送 Prompt/消息并异步得到模型响应。

### ChatResponse

模型调用返回的响应对象。

### response.Text

取得响应中的文本。
