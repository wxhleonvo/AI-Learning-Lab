## 13. notes.md 必答

1. 什么是 Prompt？
答：指用户输入的文本，要求，问题，指令等。
2. 什么是 System Message？
答：指系统角色，用于设置模型的行为和规则。
3. 什么是 User Message？
答：指用户角色，用于输入用户的问题或指令。
4. System 和 User 有什么区别？
答：System Message 用于设置模型的行为和规则，User Message 用于输入用户的问题或指令。
5. 为什么同一句 User 输入，不同 System Prompt 会得到不同结果？
答：因为 System Prompt 是模型的行为和规则，如果修改了后会以不同的维度，不同专业领域来回答问题。
6. 多轮对话为什么需要保存 ChatMessage？
答：因为模型是无状态的，需要应用保存历史消息，并在下一次请求中携带相关上下文。
7. 为什么不能只把所有内容拼成一个大字符串？
答：因为模型是无状态的，需要应用保存历史消息，并在下一次请求中携带相关上下文。
8. `ChatRole` 提供了什么信息？
答：`ChatRole` 提供了角色信息，用于设置模型的行为和规则。
9. 为什么 Message History 对 RAG / Agent 也重要？
答：因为 RAG / Agent 是基于历史消息的，需要考虑前文来回答问题。
10. 100 轮对话是否应该全部发送给模型？
答：因为模型是无状态的，需要应用保存历史消息，并在下一次请求中携带相关上下文。

# 上下文窗口内容
答： 上下文窗口内容是指模型在处理文本时，考虑的前文内容。每次调用时发送给模型的全部消息。

# Token 是什么？
Token 是模型处理文本的最小单位，大致规则：

英文：约 1 个单词 ≈ 1~2 个 token
中文：约 1 个汉字 ≈ 1~2 个 token
100 个 token ≈ 75 个英文单词 或 约 50~70 个汉字

# 上下文窗口有多大，跟什么有关？
答：跟模型本身有关。不同模型有不同的上下文窗口（Context Window）上限：

模型	上下文窗口
GPT-3.5	4K / 16K tokens
GPT-4	8K / 32K / 128K tokens
GPT-4o	128K tokens
Claude 3.5 Sonnet	200K tokens
你在 Program.cs#L8 中 config["ModelName"] 指定的模型，决定了你的上下文窗口大小。
