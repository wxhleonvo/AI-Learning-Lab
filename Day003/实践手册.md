## 0. 今天必须掌握的结论

今天只解决一个核心问题：

> **如何把上一轮对话作为下一轮请求的一部分，再发送给 LLM？**

最终应该能够解释：

```text
第 1 轮
User: 我叫张三
        ↓
LLM
        ↓
Assistant: 你好，张三

第 2 轮
System: 你是一个助手
User: 我叫张三
Assistant: 你好，张三
User: 我叫什么？
        ↓
LLM
        ↓
Assistant: 你叫张三
```

关键认知：

```text
LLM ≠ 自动永久记住聊天记录

应用程序
    ↓
维护 Conversation History
    ↓
每次请求携带相关 History
    ↓
IChatClient
    ↓
LLM
```

Microsoft 当前 `IChatClient` 文档明确说明，`GetResponseAsync` 可以接收消息列表作为对话历史；对于无状态服务，调用方通常负责维护历史，并把响应消息加入后续请求。

# 6. 实验一：两轮对话

## 6.1 Program.cs

先实现最小版本：

```csharp
using Microsoft.Extensions.AI;
using Microsoft.Extensions.Configuration;
using OpenAI;

IConfigurationRoot config = new ConfigurationBuilder()
    .AddUserSecrets<Program>()
    .Build();

string? model = config["ModelName"];
string? key = config["OpenAIKey"];

IChatClient client =
    new OpenAIClient(key)
        .GetChatClient(model)
        .AsIChatClient();

List<ChatMessage> history =
[
    new(ChatRole.System, """
        你是一个简洁、友好的中文助手。
        """)
];

// 第一轮
history.Add(new(ChatRole.User, "我叫张三。"));

ChatResponse response1 =
    await client.GetResponseAsync(history);

Console.WriteLine($"AI: {response1.Text}");

// 把 AI 回复加入历史
history.AddMessages(response1);

// 第二轮
history.Add(new(ChatRole.User, "我叫什么？"));

ChatResponse response2 =
    await client.GetResponseAsync(history);

Console.WriteLine($"AI: {response2.Text}");
```

运行：

```powershell
dotnet run
```

# 8. 实验三：故意删除 Assistant History

把：

```csharp
history.AddMessages(response1);
```

暂时注释：

```csharp
// history.AddMessages(response1);
```

再次运行。

观察：

```text
System: ...
User: 我叫张三
User: 我叫什么？
```

模型可能仍然回答“张三”。

不要得出：

> Assistant 回复没有用。

正确认知是：

**完整保存 User + Assistant 的对话轨迹，是通用的多轮聊天做法。**

例如：

```text
User: 给我制定学习计划
Assistant: ...
User: 第二阶段呢？
```

如果不保存上一轮 Assistant：

```text
User: 给我制定学习计划
User: 第二阶段呢？
```

模型看到的上下文已经改变。

因此通常保存：

```text
User
 ↓
Assistant
 ↓
User
 ↓
Assistant
```

# 9. 实验四：实现真正的 Console Chat

把程序改成：

```text
你：我叫张三
AI：你好，张三！

你：我喜欢 C#
AI：很好……

你：我叫什么？
AI：你叫张三。

你：我喜欢什么？
AI：你喜欢 C#。
```

参考实现：

```csharp
using Microsoft.Extensions.AI;
using Microsoft.Extensions.Configuration;
using OpenAI;

IConfigurationRoot config = new ConfigurationBuilder()
    .AddUserSecrets<Program>()
    .Build();

string? model = config["ModelName"];
string? key = config["OpenAIKey"];

IChatClient client =
    new OpenAIClient(key)
        .GetChatClient(model)
        .AsIChatClient();

List<ChatMessage> history =
[
    new(ChatRole.System, """
        你是一个友好的中文 AI 助手。
        请根据当前对话历史回答用户。
        """)
];

while (true)
{
    Console.Write("你：");
    string? input = Console.ReadLine();

    if (string.IsNullOrWhiteSpace(input))
    {
        continue;
    }

    if (input.Equals("exit", StringComparison.OrdinalIgnoreCase))
    {
        break;
    }

    history.Add(new(ChatRole.User, input));

    ChatResponse response =
        await client.GetResponseAsync(history);

    Console.WriteLine($"AI：{response.Text}");

    history.AddMessages(response);
}
```

退出：

```text
exit
```

# 11. 实验六：模拟多个会话

现在思考：

如果有：

```text
用户 A
用户 B
```

不能让所有人共享：

```csharp
List<ChatMessage> history;
```

否则可能发生：

```text
用户 A：
我叫张三。

用户 B：
我叫什么？
```

模型可能回答：

```text
张三
```

这是严重的数据隔离问题。

## 11.1 用 Dictionary 模拟

```csharp
Dictionary<string, List<ChatMessage>> conversations = [];
```

例如：

```csharp
string conversationId = "user-001";

if (!conversations.ContainsKey(conversationId))
{
    conversations[conversationId] =
    [
        new(ChatRole.System, """
            你是一个友好的中文 AI 助手。
            """)
    ];
}

List<ChatMessage> history =
    conversations[conversationId];
```

理解：

```text
ConversationId
      │
      ├── user-001
      │     └── History A
      │
      ├── user-002
      │     └── History B
      │
      └── user-003
            └── History C
```

今天不要求做数据库。

# 12. 非常重要：IChatClient 不等于“记忆”

不要形成：

```text
IChatClient
    ↓
自动记住所有聊天
```

当前实验是：

```text
你的代码
    ↓
维护 List<ChatMessage>
    ↓
IChatClient.GetResponseAsync(history)
    ↓
LLM
```

Microsoft 官方文档明确区分无状态和有状态服务：

```text
无状态
调用方保存 History
        ↓
每次请求携带 History
```

而部分有状态服务可以使用：

```text
ConversationId
```

让服务管理会话状态。

所以未来 Web API 可以是：

```text
POST /chat

{
    "conversationId": "abc",
    "message": "我叫什么？"
}
```

服务器再：

```text
conversationId
      ↓
找到 History
      ↓
IChatClient
      ↓
LLM
```

这就是后面 AI Developer Assistant 的基础。

# 27. 最终验收问题

> **“LLM 的多轮对话到底是谁记住的？”**

标准答案核心：

```text
通常不是模型永久记住了。

应用程序维护 Conversation History，
每一轮把相关 ChatMessage 历史发送给 IChatClient，
模型基于这些消息生成下一轮响应，
然后应用再把 Assistant 响应加入 History。
```
