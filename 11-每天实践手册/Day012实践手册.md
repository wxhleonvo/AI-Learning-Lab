# 5. 实验一：生成第一个 Embedding

```csharp
using System.Text;
using Microsoft.Extensions.AI;
using Microsoft.Extensions.Configuration;
using OpenAI;
using System.ClientModel;
using System.Numerics.Tensors;   // 余弦相似度 TensorPrimitives.CosineSimilarity

Encoding.RegisterProvider(CodePagesEncodingProvider.Instance);
Console.InputEncoding = Encoding.GetEncoding(936);

IConfigurationRoot config = new ConfigurationBuilder()
    .AddJsonFile("appsettings.json", optional: false)
    .AddUserSecrets<Program>()
    .Build();

string? key = config["DashScopeKey"];
string? embeddingModel = config["EmbeddingModel"] ?? "text-embedding-v3";

OpenAIClientOptions clientOptions = new()
{
    Endpoint = new Uri("https://dashscope.aliyuncs.com/compatible-mode/v1")
};

// 关键：GetEmbeddingClient 返回 IEmbeddingClient，AsIEmbeddingGenerator 转成通用接口
IEmbeddingGenerator<string, Embedding<float>> generator =
    new OpenAIClient(new ApiKeyCredential(key!), clientOptions)
        .GetEmbeddingClient(embeddingModel)
        .AsIEmbeddingGenerator();

Console.WriteLine("===== 实验一：生成第一个 Embedding =====");

string text = "苹果手机的续航怎么样？";
ReadOnlyMemory<float> vector = await generator.GenerateVectorAsync(text);

Console.WriteLine($"  文本：{text}");
Console.WriteLine($"  向量维度：{vector.Length}");
Console.WriteLine($"  前 10 个值：{string.Join(", ", vector.Span[..10].ToArray().Select(v => v.ToString("F4")))}");
Console.WriteLine($"  向量模长：{vector.Span.ToArray().Select(v => v * v).Sum():F4}（接近 1 表示已归一化）");
```

### 预期结果

```text
文本：苹果手机的续航怎么样？
向量维度：1024（或 1536，取决于模型）
前 10 个值：0.0123, -0.0456, 0.0789, ...
向量模长：1.0000（归一化后）
```

### 必须得出的结论

```text
Embedding = 一段文本 → 一个浮点数数组（向量）
向量维度由模型决定（text-embedding-v3 默认 1024 维）
归一化后的向量模长 = 1，此时余弦相似度 = 点积
```

# 6. 实验二：余弦相似度——语义相近的文本距离近

```csharp
Console.WriteLine("\n===== 实验二：余弦相似度 =====");

string[] texts =
{
    "苹果手机的续航怎么样？",
    "iPhone battery life is poor.",
    "今天天气真好，适合出去散步。",
    "The weather is beautiful today.",
};

// 批量生成 Embedding
var embeddings = await generator.GenerateAsync(texts);

// 两两计算余弦相似度
Console.WriteLine("  相似度矩阵（行 i vs 列 j）：");
Console.Write("         ");
for (int j = 0; j < texts.Length; j++)
    Console.Write($"  T{j + 1}     ");
Console.WriteLine();

for (int i = 0; i < texts.Length; i++)
{
    Console.Write($"  T{i + 1}: ");
    for (int j = 0; j < texts.Length; j++)
    {
        float sim = TensorPrimitives.CosineSimilarity(embeddings[i].Vector.Span, embeddings[j].Vector.Span);
        Console.Write($"{sim,7:F3}  ");
    }
    Console.WriteLine($"  （{texts[i][..Math.Min(12, texts[i].Length)]}）");
}
```

### 预期结果

```text
  T1(苹果续航) vs T2(iPhone battery):  ~0.85  ← 跨语言语义相近！
  T1 vs T3(天气):                       ~0.10  ← 语义无关
  T3 vs T4(weather):                    ~0.90  ← 跨语言同义
  T1 vs T1:                             1.000  ← 自身
```

### 必须得出的结论

```text
语义相近 → 向量夹角小 → 余弦相似度接近 1
语义无关 → 向量近似正交 → 余弦相似度接近 0
语义相反 → 余弦相似度可能为负（取决于模型）
Embedding 能捕捉跨语言语义："苹果手机" 和 "iPhone" 距离很近
这就是 RAG 能做语义检索的基础
```

# 7. 实验三：极简语义搜索

```csharp
Console.WriteLine("\n===== 实验三：极简语义搜索 =====");

// 知识库：3 段文本
string[] knowledgeBase =
{
    "苹果公司发布了新款 iPhone，搭载 A18 芯片，续航提升 20%。",
    "微软推出 Windows 12，集成 Copilot AI 助手，支持多任务分屏。",
    "谷歌发布 Pixel 9，搭载 Tensor G4 芯片，相机算法大幅升级。",
};

// 1. 给知识库每条生成 Embedding
var kbEmbeddings = await generator.GenerateAsync(knowledgeBase);

// 2. 用户查询
string query = "哪款手机的电池续航更好？";
ReadOnlyMemory<float> queryVec = await generator.GenerateVectorAsync(query);

// 3. 计算 query 与每条知识库的相似度，排序
var results = knowledgeBase
    .Select((text, idx) => new
    {
        Text = text,
        Score = TensorPrimitives.CosineSimilarity(queryVec.Span, kbEmbeddings[idx].Vector.Span)
    })
    .OrderByDescending(r => r.Score)
    .ToList();

Console.WriteLine($"  查询：{query}");
Console.WriteLine("  搜索结果（按相似度降序）：");
for (int i = 0; i < results.Count; i++)
{
    Console.WriteLine($"    {i + 1}. [相似度={results[i].Score:F3}] {results[i].Text}");
}
```

### 预期结果

```text
查询：哪款手机的电池续航更好？
搜索结果：
  1. [相似度=0.78] 苹果公司发布了新款 iPhone...续航提升 20%。  ← 命中
  2. [相似度=0.45] 谷歌发布 Pixel 9...相机算法大幅升级。
  3. [相似度=0.30] 微软推出 Windows 12...
```

### 必须得出的结论

```text
语义搜索 ≠ 关键词搜索
查询里没有 "iPhone" 这个词，但 Embedding 知道它和 "苹果手机" 语义近
Top-1 命中了讲续航的那条
这就是 RAG 的核心：把知识库向量化，查询向量化，按相似度排序
```

# 8. 实验四：Embedding 维度对比

text-embedding-v3 支持 1024 / 768 / 512 维。切换维度看相似度是否变化。

```csharp
Console.WriteLine("\n===== 实验四：Embedding 维度对比 =====");

// 注意：text-embedding-v3 通过 dimensions 参数控制维度
// 在 M.E.AI 里通过 EmbeddingGenerationOptions 传递
string[] testTexts = { "苹果手机续航", "iPhone battery" };

// 不同维度的生成（如果模型支持）
int[] dimensions = { 1024, 512, 256 };
foreach (var dim in dimensions)
{
    try
    {
        var opts = new EmbeddingGenerationOptions { Dimensions = dim };
        var embs = await generator.GenerateAsync(testTexts, opts);
        float sim = TensorPrimitives.CosineSimilarity(embs[0].Vector.Span, embs[1].Vector.Span);
        Console.WriteLine($"  维度={dim,4}  向量长度={embs[0].Vector.Length,4}  相似度={sim:F4}");
    }
    catch (Exception ex)
    {
        Console.WriteLine($"  维度={dim,4}  不支持或报错：{ex.Message[..Math.Min(60, ex.Message.Length)]}");
    }
}

// 如果你的模型不支持动态维度，上面会报错，改用以下静态对比：
// 手动用两个不同的 embedding 模型（如 text-embedding-v2 1536 维 vs v3 1024 维）
```

### 必须得出的结论

```text
维度越高 → 表达能力越强 → 存储/计算成本越高
维度越低 → 越省资源 → 可能损失精度
text-embedding-v3 支持动态降维：1024 → 512 → 256，相似度基本不变
RAG 场景通常 512-1024 维足够（平衡精度和成本）
```

# 9. 实验五：同一个模型才能比——跨模型 Embedding 不兼容

```csharp
Console.WriteLine("\n===== 实验五：跨模型 Embedding 不兼容 =====");

// 用 text-embedding-v3 生成 "苹果" 的向量
var v3Vec = await generator.GenerateVectorAsync("苹果手机");

// 如果有另一个模型（如 text-embedding-v2），生成同一个词的向量
// 然后算相似度，会发现相似度很低（因为两个模型的向量空间不同）
// 这里用模拟说明：

Console.WriteLine("  注意：不同 Embedding 模型的向量空间完全不同！");
Console.WriteLine("  text-embedding-v3 的 1024 维向量 和 text-embedding-v2 的 1536 维向量");
Console.WriteLine("  即使是同一个词，算出来的相似度也接近 0（因为空间不同）");
Console.WriteLine();
Console.WriteLine("  规则：");
Console.WriteLine("    ① 知识库和查询必须用同一个 Embedding 模型");
Console.WriteLine("    ② 换模型 = 重新向量化整个知识库");
Console.WriteLine("    ③ 向量维度不同的两个向量无法直接计算相似度");
```

### 必须得出的结论

```text
Embedding 没有「通用向量空间」
每个模型有自己的向量空间，跨模型不兼容
生产项目：选定一个 Embedding 模型后，全链路统一用它
换模型是重大决策（要重建所有向量索引）
```

# 10. 实验六：Embedding 的三个典型应用场景

```csharp
Console.WriteLine("\n===== 实验六：Embedding 三大应用场景 =====");

// 场景 1：语义搜索（实验三已演示）
Console.WriteLine("  场景 1：语义搜索（RAG 检索）");
Console.WriteLine("    知识库向量化 → 查询向量化 → 相似度排序 → Top-K");
Console.WriteLine();

// 场景 2：聚类
Console.WriteLine("  场景 2：文本聚类");
string[] clusterTexts =
{
    "iPhone 15 发布", "Pixel 9 评测", "Galaxy S24 对比",   // 手机类
    "美联储加息", "A股大涨", "比特币突破 10 万",          // 金融类
    "欧冠决赛", "NBA 季后赛", "世界杯预选赛",              // 体育类
};
var clusterVecs = await generator.GenerateAsync(clusterTexts);
Console.WriteLine("    同类文本相似度 > 0.7，异类 < 0.3 → 可自动聚类");
Console.WriteLine();

// 场景 3：分类（用 Embedding + 简单距离做零样本分类）
Console.WriteLine("  场景 3：零样本分类");
string[] categories = { "科技", "金融", "体育" };
var catVecs = await generator.GenerateAsync(categories);
string item = "苹果发布新款 MacBook Pro";
var itemVec = await generator.GenerateVectorAsync(item);
var scores = categories.Select((c, i) => (Cat: c, Score: TensorPrimitives.CosineSimilarity(itemVec.Span, catVecs[i].Vector.Span)));
Console.WriteLine($"    文本：{item}");
foreach (var s in scores.OrderByDescending(x => x.Score))
    Console.WriteLine($"      {s.Cat}: {s.Score:F3}");
```

### 必须得出的结论

```text
Embedding 的三大应用：
  ① 语义搜索（RAG 核心）
  ② 聚类（无监督分组）
  ③ 分类/推荐（零样本，不需要训练）
本质都是「向量空间距离 = 语义距离」
```
