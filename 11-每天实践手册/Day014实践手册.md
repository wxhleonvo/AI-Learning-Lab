## 1. 今日目标

完成后，你必须拥有一个**自己从零搭出来的、整合了 Phase 1 全部技能**的项目：

1. **配置驱动的双模型架构**：云端模型（qwen3.7-flash）为主、本地模型（Ollama qwen2.5:7b）为备，改配置即可切换（Day001/004/013）。
2. **Prompt 模板 + Few-shot**：模板文件渲染、变量缺失 fail-fast（Day008/009 的踩坑经验）。
3. **结构化输出**：评论分析结果强类型化为 `ReviewAnalysis`（Day006）。
4. **可靠性三件套**：超时（30s）+ 重试（3 次指数退避）+ 降级（云端失败自动切本地）（Day010/013）。
5. **Token 消耗统计**：服务层累计 InputTokens / OutputTokens / TotalTokens（Day011）。
6. **Embedding 语义检索**：给新评论找最相似的历史评论（Day012）。
7. **故障注入演练**：故意把云端搞挂，亲眼看到降级链路工作（Day010）。
8. **（可选）流式输出**：客服回复打字机效果（Day005）。

这个项目就是你 Phase 2 做 Web 应用时的「内核」——Phase 2 只是给它套上 ASP.NET Core API 和 Vue 界面。

# 5. 整体架构：智能评论分析器

```text
                         ┌──────────────── Program.cs（编排层）────────────────┐
                         │                                                     │
 历史评论 5 条 ──────────►│  SimilarReviewFinder ──► 云端 Embedding 向量化      │
                         │        │                                            │
                         │        ▼（新评论也向量化，余弦相似度 Top-3）          │
                         │                                                     │
 新评论 ────────────────►│  ReviewAnalyzerService                               │
                         │    ├─ 加载 Prompts/review-analysis.txt 模板          │
                         │    ├─ 注入 examples.json 的 3 个 Few-shot 示例       │
                         │    ├─ 云端 IChatClient（主）                         │
                         │    │    └─ 30s 超时 → 失败重试 3 次（1s/2s/4s 退避） │
                         │    ├─ 本地 IChatClient（备，Ollama）── 云端全挂才用  │
                         │    ├─ 结构化输出 ReviewAnalysis（失败再手解 RawText）│
                         │    └─ TokenUsage 累计（输入/输出/总计）              │
                         │                                                     │
                         └─────────────────────────────────────────────────────┘
```

**一次请求的生命周期**：

1. 启动时：历史评论批量向量化，存入内存「伪向量库」。
2. 用户给一条新评论。
3. 服务渲染 Prompt（模板 + 3 个 Few-shot）。
4. 调云端模型：30s 超时、最多 3 次指数退避重试。
5. 云端 3 次全败 → 自动降级本地 Ollama 再试。
6. 结构化结果：先 M.E.AI 内置解析，失败再手动反序列化 RawText（本地模型兜底）。
7. 打印：情感/评分/关键词/摘要/建议回复 + 模型来源 + 重试次数 + Token 消耗。
8. Embedding 语义检索 Top-3 相似历史评论（业务价值：历史工单怎么处理的，可参考）。

## Services/TemplateRenderer.cs（Day009 踩坑：变量缺失必须 fail-fast）

```csharp
using System.Text.RegularExpressions;

/// <summary>
/// 极简模板渲染：{{变量名}} 占位符替换（Day009）
/// 变量缺失时直接抛异常——SK 模板静默置空会导致模型幻觉，绝不能放过
/// </summary>
public static partial class TemplateRenderer
{
    public static string Render(string template, Dictionary<string, string> variables)
    {
        // 1. 找出模板里所有占位符，和传入变量做差集
        var missing = PlaceholderRegex()
            .Matches(template)
            .Select(m => m.Groups[1].Value)
            .Where(name => !variables.ContainsKey(name))
            .Distinct(StringComparer.Ordinal)
            .ToList();

        if (missing.Count > 0)
            throw new InvalidOperationException($"模板缺少变量值：{string.Join("、", missing)}");

        // 2. 替换
        string result = template;
        foreach (var (name, value) in variables)
            result = result.Replace($"{{{{{name}}}}}", value);

        // 3. 渲染后仍有残留占位符 → 报错
        if (PlaceholderRegex().IsMatch(result))
            throw new InvalidOperationException("渲染后仍存在未替换的占位符");

        return result;
    }

    [GeneratedRegex(@"\{\{\s*(\w+)\s*\}\}")]
    private static partial Regex PlaceholderRegex();
}
```

# 9. 步骤四：分析服务——重试 + 超时 + 降级 + Token 统计（Day010 / Day011 / Day013）

新建 `Services/ReviewAnalyzerService.cs`。这是今天的**核心文件**，包含可靠性三层防线：

```csharp
using System.Diagnostics;
using System.Text;
using System.Text.Json;
using System.Text.Json.Serialization;
using Microsoft.Extensions.AI;

/// <summary>一次分析的完整结果</summary>
public class AnalyzeResult
{
    public ReviewAnalysis? Analysis { get; init; }   // 解析失败为 null
    public string RawText { get; init; } = "";       // 模型原始输出（排错用）
    public string ModelSource { get; init; } = "unknown"; // cloud:qwen3.7-flash / local:qwen2.5:7b
    public int Attempts { get; init; }               // 实际尝试次数
    public long ElapsedMs { get; init; }
    public TokenUsage TokenUsage { get; init; } = new();
}

/// <summary>Token 累计统计（Day011）——重试可能产生多次调用，必须累计而不是只看最后一次</summary>
public class TokenUsage
{
    public long InputTokens { get; private set; }
    public long OutputTokens { get; private set; }
    public long TotalTokens { get; private set; }

    public void Add(UsageDetails? usage)
    {
        if (usage is null) return;
        // 注意：10.9.0 属性名是 InputTokenCount / OutputTokenCount / TotalTokenCount
        // （早期预览版叫 InputTokens / OutputTokens / TotalTokens，已改名）
        InputTokens += usage.InputTokenCount ?? 0;
        OutputTokens += usage.OutputTokenCount ?? 0;
        TotalTokens += usage.TotalTokenCount ?? 0;
    }
}

/// <summary>
/// 评论分析服务（Day006/008/009/010/011/013 集大成）
/// 主客户端（云端）失败重试 3 次，仍失败 → 降级备客户端（本地）
/// </summary>
public class ReviewAnalyzerService(IChatClient primary, IChatClient? fallback)
{
    private static readonly JsonSerializerOptions JsonOpts = new()
    {
        PropertyNameCaseInsensitive = true,
        // Day009 踩坑：枚举默认序列化成数字，必须加字符串转换器，反序列化两处都要加
        Converters = { new JsonStringEnumConverter() }
    };

    public async Task<AnalyzeResult> AnalyzeAsync(string review, CancellationToken ct = default)
    {
        string prompt = BuildPrompt(review);
        var options = new ChatOptions
        {
            Temperature = 0.1f,
            MaxOutputTokens = 2000
            // 非推理模型 2000 足够；若换 glm-5.2 等推理模型要提到 4000（Day011 结论）
        };

        // 第一层：云端（含 3 次重试）
        AnalyzeResult? result = await CallWithRetryAsync(primary, "cloud", prompt, options, ct);

        // 第二层：本地降级
        if (result is null && fallback is not null)
        {
            Console.WriteLine("  ⚠️ 云端重试 3 次均失败，降级到本地模型……");
            result = await CallWithRetryAsync(fallback, "local", prompt, options, ct);
        }

        return result ?? throw new InvalidOperationException(
            "云端与本地模型均不可用：请检查网络 / DashScope Key / Ollama 服务是否启动");
    }

    /// <summary>带超时 + 指数退避重试的调用，返回 null 表示 3 次全败</summary>
    private static async Task<AnalyzeResult?> CallWithRetryAsync(
        IChatClient client, string source, string prompt, ChatOptions options, CancellationToken ct)
    {
        const int maxAttempts = 3;
        var usage = new TokenUsage();
        var sw = Stopwatch.StartNew();

        for (int attempt = 1; attempt <= maxAttempts; attempt++)
        {
            try
            {
                // 第三层：单次调用 30 秒超时（Day010）
                using var cts = CancellationTokenSource.CreateLinkedTokenSource(ct);
                cts.CancelAfter(TimeSpan.FromSeconds(30));

                ChatResponse<ReviewAnalysis> response = await client.GetResponseAsync<ReviewAnalysis>(
                    prompt, options, cancellationToken: cts.Token);

                usage.Add(response.Usage);  // Token 累计（Day011）

                // 结构化解析：先用 M.E.AI 内置解析（Day006）
                ReviewAnalysis? analysis = null;
                if (response.TryGetResult(out var parsed))
                {
                    analysis = parsed;
                }
                else
                {
                    // 本地小模型可能不认 response_format：降级手解 RawText（Day013 结论）
                    try { analysis = JsonSerializer.Deserialize<ReviewAnalysis>(response.Text ?? "", JsonOpts); }
                    catch (JsonException) { /* 交给重试或返回 RawText */ }
                }

                if (analysis is not null || attempt == maxAttempts)
                {
                    sw.Stop();
                    return new AnalyzeResult
                    {
                        Analysis = analysis,
                        RawText = response.Text ?? "",
                        ModelSource = $"{source}:{response.ModelId}",
                        Attempts = attempt,
                        ElapsedMs = sw.ElapsedMilliseconds,
                        TokenUsage = usage
                    };
                }

                Console.WriteLine($"  [{source}] 第 {attempt} 次结构化解析失败，准备重试……");
            }
            catch (Exception ex)
            {
                if (ct.IsCancellationRequested) throw;  // 调用方主动取消，不重试

                Console.WriteLine($"  [{source}] 第 {attempt} 次失败：{ex.GetType().Name}");
                if (attempt < maxAttempts)
                {
                    int backoff = BackoffMs(attempt);
                    Console.WriteLine($"           {backoff}ms 后重试（指数退避）……");
                    await Task.Delay(backoff, ct);
                }
            }
        }

        sw.Stop();
        return null;
    }

    /// <summary>指数退避：1s → 2s → 4s（Day010）</summary>
    private static int BackoffMs(int attempt) =>
        (int)TimeSpan.FromSeconds(Math.Pow(2, attempt - 1)).TotalMilliseconds;

    /// <summary>组装 Prompt：模板 + Few-shot（Day008 / Day009）</summary>
    private static string BuildPrompt(string review)
    {
        string template = File.ReadAllText("Prompts/review-analysis.txt");
        string examplesJson = File.ReadAllText("examples.json");

        List<FewShotExample> shots = JsonSerializer.Deserialize<List<FewShotExample>>(examplesJson, JsonOpts)
            ?? throw new InvalidDataException("examples.json 反序列化为空");

        var sb = new StringBuilder();
        foreach (var shot in shots)
        {
            sb.AppendLine($"评论：{shot.Review}");
            sb.AppendLine($"输出：{JsonSerializer.Serialize(shot.Analysis, JsonOpts)}");
            sb.AppendLine();
        }

        // 模板变量缺失会在这里直接抛异常（Day009 fail-fast）
        return TemplateRenderer.Render(template, new Dictionary<string, string>
        {
            ["examples"] = sb.ToString().TrimEnd(),
            ["review"] = review
        });
    }

    private sealed class FewShotExample
    {
        public string Review { get; set; } = "";
        public ReviewAnalysis Analysis { get; set; } = new();
    }
}
```

### 必须理解的三个设计点

```text
① 重试 vs 降级的边界：
   重试 = 同一个客户端再试（对付限流/超时等瞬时故障）
   降级 = 换一个客户端（对付 Key 失效/服务宕路等持续性故障）
   顺序：先重试用尽，再降级。

② Token 为什么累计：
   重试 3 次 = 最多 3 次真实 API 调用，每次都计费。
   只看最后一次的 Usage 会漏掉失败调用的成本（Day011 的预算意识）。

③ 结构化输出双保险：
   M.E.AI 内置解析（走 response_format）优先；
   本地小模型不支持时，RawText 手动 JsonSerializer.Deserialize 兜底。
```

# 10. 步骤五：Embedding 语义检索（Day012）

新建 `Services/SimilarReviewFinder.cs`。这是 Day012 极简语义搜索的「内存版向量库」：

> 注意：10.9.0 起余弦相似度 API 是 `System.Numerics.Tensors.TensorPrimitives.CosineSimilarity`
> （早期预览版的 `Microsoft.Extensions.AI.CosineSimilarity` 已移除，`System.Numerics.Tensors`
> 随 Microsoft.Extensions.AI 传递引用，无需单独加包）。

```csharp
using Microsoft.Extensions.AI;
using System.Numerics.Tensors;

public record HistoricalReview(string Id, string Text, string Category);

/// <summary>
/// 相似评论检索：历史评论向量化入库，查询向量化后按余弦相似度 Top-K（Day012）
/// 正式项目这里换成 Vector DB（Day044），接口签名不用变
/// </summary>
public class SimilarReviewFinder(IEmbeddingGenerator<string, Embedding<float>> generator)
{
    private readonly List<(HistoricalReview Review, ReadOnlyMemory<float> Vector)> _store = [];

    /// <summary>批量入库（启动时调用一次）</summary>
    public async Task AddBatchAsync(IEnumerable<HistoricalReview> reviews)
    {
        var list = reviews.ToList();
        var embeddings = await generator.GenerateAsync(list.Select(r => r.Text));

        foreach (var (review, emb) in list.Zip(embeddings))
            _store.Add((review, emb.Vector));
    }

    /// <summary>语义检索：返回与 query 最相似的 topK 条历史评论</summary>
    public async Task<List<(HistoricalReview Review, float Score)>> FindAsync(string query, int topK = 3)
    {
        ReadOnlyMemory<float> queryVector = await generator.GenerateVectorAsync(query);

        return _store
            .Select(x => (x.Review,
                          Score: TensorPrimitives.CosineSimilarity(queryVector.Span, x.Vector.Span)))
            .OrderByDescending(x => x.Score)
            .Take(topK)
            .ToList();
    }
}
```
