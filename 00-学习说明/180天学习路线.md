# 180天 AI Application Engineer / LLM Engineer 学习路线

> **定位：总目录 / 学习地图**
>
> 本文件只负责回答：180天每天学什么、做什么、形成什么能力。
> 每一天的详细执行步骤单独放在 `DayXXX/实践手册.md`。

## 一、目标

从 C# + ASP.NET Core + Vue 全栈/后端开发，逐步转向：
- AI Application Engineer
- LLM Engineer
- GenAI Engineer
- AI Engineer
- RAG / Agent Engineer

核心路线：

```text
C# / ASP.NET Core
↓
.NET AI / LLM API
↓
Prompt / Message / Chat
↓
Structured Output / Streaming
↓
Embedding
↓
RAG
↓
Tool Calling
↓
Agent
↓
AI Engineering
↓
Python / Hugging Face
↓
企业级 AI 应用与系统设计
↓
作品集 + 面试
```

## 四、每日实践手册标准

每个 Day 的独立手册原则上包含：

1. 今日目标
2. 必须理解的概念
3. 学习资料与链接
4. 今天具体看什么
5. 环境准备
6. 详细实践步骤
7. 可运行代码
8. 预期结果
9. 实验记录
10. 结果分析
11. 常见问题与 Troubleshooting
12. 知识验收
13. 面试题
14. GitHub 产出
15. Git Commit
16. 今日学习记录
17. 与下一天衔接

> 代码实验、RAG、Agent、工程实践需要写得足够细，确保只看当天手册也能完成。
> 复盘类日可以短一些，但仍然要有明确的操作、产出和验收。
